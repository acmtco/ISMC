# scripts

Служебные скрипты, каждый запускается отдельно, без камеры и GPU.

- `make_synthetic.py` — генерация синтетического бенчмарка с честным ground
  truth внедрённых отклонений, в `data/synthetic/` и `data/benchmark/`
  (`scripts/synth/`).
- `eval_end2end.py` — сквозная оценка на `data/benchmark/`, единственный
  источник чисел для `docs/04-metrics.md` (`scripts/eval/`): детекция и
  трекинг — только если в `models/` появятся веса детектора (иначе честно
  помечены "нет данных"); состояние, машино-часы и отклонения — на
  реалистичном прогоне перцепции по кадрам синтетики уже сейчас.
- `ingest_camera.py` — приём кадров с камеры (`live`) или из папки (`replay`);
  каркас — в реальном деплое эту роль играет `services/api/scheduler.py`
  (опрос камер по расписанию), бизнес-логика здесь не реализована.
