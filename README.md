# Хронограф

Автоматизированный сервис поиска нарушений на строительных площадках.
Задача №7 конкурса «Лидеры цифровой трансформации 2026», постановщик —
Департамент градостроительной политики города Москвы.

Команда CyberCrew.

## О чём это

Обычная видеоаналитика отвечает на вопрос «есть ли техника на площадке».
Этого мало: график производства работ написан не в штуках техники, а в
объёмах и сроках, и сравнить одно с другим напрямую нельзя.

Хронограф переводит снимки с камер в **машино-часы** — ту же единицу, в
которой считают смету и календарный план. План и факт сравниваются без
посредников, а из накопленных машино-часов получаются индекс выполнения по
срокам, прогнозная дата окончания работы и оценка, сколько техники нужно
добавить, чтобы уложиться в срок.

```
снимок ──► качество кадра ──► детекция ──► трекинг ──► зона ──► состояние
                                                                    │
                                              машино-часы (сутки × зона × класс)
                                                                    │
     график работ ──► плановые часы ──► сверка ──► отклонение Р0–Р4 ──► прогноз
```

## Быстрый запуск

```bash
docker compose --profile demo up
```

Интерфейс — http://localhost:5173, документация API — http://localhost:8000/docs

Без Docker:

```bash
python3.11 -m venv .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/uvicorn services.api.main:app --port 8000
```

и в отдельном терминале:

```bash
cd web && npm install && npm run dev
```

Камера, GPU и доступ в интернет для запуска не нужны: система работает в
режиме `replay` на предзаписанных снимках.

## Проверка

```bash
.venv/bin/python -m pytest -q && .venv/bin/ruff check .
```

Тесты не требуют сети, GPU и камеры.

## Устройство

| Каталог | Назначение |
|---|---|
| `services/perception/` | кадр → детекции → треки → состояние техники |
| `services/analytics/` | машино-часы, ресурсный отпечаток, правила отклонений, прогноз |
| `services/api/` | FastAPI: двенадцать эндпоинтов, планировщик, PDF-акты |
| `web/` | интерфейс на React, пять экранов |
| `scripts/` | синтетический бенчмарк, обучение детектора, сквозная оценка |
| `config/` | все пороги и веса правил |
| `docs/` | принципы, контракты данных, методика, метрики |

Ни одного порога нет в коде: параметры правил вынесены в `config/*.yaml`,
справочные значения — в `data/ref/*.json`. Методику можно править без
программиста.

## Зависимости

Сервису для работы нужен лишь базовый набор. Всё тяжёлое вынесено в
необязательные группы:

```bash
pip install .            # работающий сервис
pip install ".[ml]"      # + обучение и инференс детектора
pip install ".[synth]"   # + генерация синтетического бенчмарка
pip install ".[eval]"    # + сквозная оценка качества
pip install ".[dev]"     # всё вместе плюс тесты и линтер
```

## Развёртывание

На сервере с Docker:

```bash
echo "HG_DOMAIN=ваш.домен" > .env
docker compose -f docker-compose.prod.yml up -d --build
```

Сертификат Let's Encrypt выпускается и продлевается автоматически.
