# web

React SPA, 5 экранов. Тёмная промышленная тема: крупные числа, плотные
таблицы, акцентный цвет — только для статусов (светофор, критичность,
доверие к данным).

## Экраны

- `/setup` — мастер из 3 шагов: импорт графика (drag&drop XLSX/XML),
  подключение камеры, разметка зон полигонами мышью прямо на кадре.
- `/live` — кадр с боксами и полупрозрачными зонами, панель «сейчас на
  площадке» по классам (работает/простаивает/на приколе), индикатор доверия.
- `/gantt` — план vs факт по машино-часам, светофор, прогнозная дата,
  слайдер «машина времени» (проигрывает весь период).
- `/deviations` — лента отклонений с фильтрами по типу/критичности; карточка
  с графиком план/факт, кадрами-уликами, рекомендацией, кнопками
  «Сформировать акт» и «Не согласен».
- `/economics` — КИТ по единицам техники, топ причин потерь, экспорт CSV.

## Типизированный клиент

`src/api/schema.d.ts` генерируется из живой OpenAPI-схемы бэкенда:

```bash
make generate-api   # из корня репозитория; см. Makefile
```

`src/api/hooks.ts` оборачивает каждый запрос в демо-фолбэк
(`src/api/demo-data.ts`) — если бэкенд недоступен или отвечает ошибкой,
экран показывает демонстрационные данные с явным баннером, а не падает
(CLAUDE.md, правило 3).

Стек: React 18 + Vite + TypeScript + Tailwind + shadcn-style компоненты
(Radix + class-variance-authority) + Recharts + `@tanstack/react-query`.

Обращается к `services/api` через `VITE_API_URL` (по умолчанию `http://localhost:8000`).
